# DS5020-Monte-Carlo-Final-Project

DS5020, Fall 2026 · Dr. Fatema Nafa
Adrien Mery (#003185537, project leader) · Alex Katzman (#003981409)

We estimate an unknown mean by averaging random draws, prove how fast that average
converges (unbiasedness, variance, the weak law, a CLT confidence interval), and
check each result numerically against a case where the true answer is known
($\mu = \pi$). The same estimator is then applied to NOAA daily weather data.

Overleaf project: https://www.overleaf.com/project/6aebbf3646d901528b89dfbf/share#69f254d9ac708e03c03cb84c2230940db0381c3767d9dc99

## Getting the raw data

The raw NOAA file is ~10–20 MB and is **not committed to git**. Running the
loader downloads it into `data/` and caches it:

```bash
python src/load_data.py
```

It pulls station `USW00014739` (Boston Logan) from NOAA NCEI's Global Historical
Climatology Network — Daily:

```
https://www.ncei.noaa.gov/data/global-historical-climatology-network-daily/access/USW00014739.csv
```

If your network blocks that host, open the URL in a browser, save the file to
`data/USW00014739.csv`, and re-run the command — it will use the cached copy.

## Reproducing the results

```bash
python src/simulate_pi.py    # simulation check behind report Section 5.2
python src/load_data.py      # real-data description behind Section 5.1
cd docs && latexmk -pdf iteration2.tex
```

The seed is fixed at `np.random.default_rng(0)`, so both of us get identical
numbers.

Iteration 3 (small example, simulation test, real data, assumption checks and
Q1-Q5) is in one notebook. Run `python src/load_data.py` first so the NOAA CSV
is cached, then run all cells from `src/`:

```bash
pip install notebook
cd src && jupyter notebook Iteration3.ipynb    # Kernel -> Restart & Run All
```

The notebook uses seed 42 (see the report) and writes
`figures/iteration3_loglog_error.png`.
